RadioRecorder 1.0.2 improves transcription of radio audio and recovery of Morse station identifiers.

- A stronger multilingual Whisper Base model replaces Tiny.
- A bundled Silero neural speech detector rejects captions invented over background noise, squelch and non-speech tones. Normal phrase context is preserved across VOX spans, while long leading silence is trimmed for inference.
- A final CW pass recovers identifiers missed during live capture, and includes candidates in both visible captions and embedded MP4 metadata. Adaptive timing handles different sending speeds and timestamps each identifier from its actual pulses.
- Default capture remains 16 kHz mono. Live rewind, per-machine playback time zones and multiple inputs remain available.

**Windows 10/11 x64:** double-click the portable EXE; no installer or administrator access is required. The speech model, audio encoder and runtime libraries are bundled.

**macOS Apple Silicon:** use the ZIP or DMG. The Mac app is ad-hoc signed and not Apple-notarized. Windows is unsigned. These are development previews, so OS security prompts may appear.

Validation includes 19 automated engine tests, timestamp regression across an inference-window boundary, synthetic English/Spanish transcription, MP4 caption/metadata export and packaged utility-process inference. Windows native libraries, model checksums and executable/archive structure were checked. Physical Windows microphone/UI testing remains outstanding. Machine-generated captions and CW candidates still require review against the audio.

`SHA256SUMS.txt` verifies the three application downloads, built and checked on GitHub's platform runners. Public `runtimes/macos` and `runtimes/windows` folders link to the current downloads and retain the original 1.0.1 binaries through Git LFS. No personal recordings or transcripts are included.
