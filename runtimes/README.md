# Runtime downloads

These folders are public. They link to the latest application downloads and retain the original 1.0.1 builds in Git LFS because each exceeds GitHub's ordinary Git file-size limit. Current builds are attached to GitHub Releases, avoiding dependency on the Git LFS download service.

- [macOS Apple Silicon](macos)
- [Windows 10/11 x64 portable](windows)
- [Direct downloads and release notes](https://github.com/strongjer/RadioRecorder/releases/tag/v1.0.2)

If cloning the source, install Git LFS to retrieve these binaries, or use `GIT_LFS_SKIP_SMUDGE=1 git clone` to fetch source only. Direct release downloads do not require Git or Git LFS.
