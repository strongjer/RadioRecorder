# macOS Apple Silicon

The links below provide the current 1.0.2 release. The binary files retained in this folder are the archived 1.0.1 preview; its local checksum file applies to those archived files. Use the release's SHA256SUMS.txt for current downloads.

- [Download ZIP](https://github.com/strongjer/RadioRecorder/releases/download/v1.0.2/RadioRecorder-1.0.2-arm64-mac.zip): unzip to obtain RadioRecorder.app.
- [Download DMG](https://github.com/strongjer/RadioRecorder/releases/download/v1.0.2/RadioRecorder-1.0.2-arm64.dmg): open and drag RadioRecorder to Applications.

For Apple Silicon Macs. This build is locally ad-hoc signed and is not Apple-notarized. macOS may require using Privacy & Security to permit the application to open. Allow microphone access when requested. Transcription downloads its model on the first real recording, then runs locally. Recordings are stored in Music/RadioRecorder.

The Mac application was tested locally with synthetic inputs, live rewind, captions and MP4 archival. Caption accuracy depends on the audio; verify generated text against the recording.
