# Runtime downloads

These folders are public and contain the built application downloads, stored using Git LFS because each exceeds GitHub's ordinary Git file-size limit.

- [macOS Apple Silicon](macos)
- [Windows 10/11 x64 portable](windows)
- [Direct downloads and release notes](https://github.com/strongjer/RadioRecorder/releases/tag/v1.0.1)

If cloning the source, install Git LFS to retrieve these binaries, or use `GIT_LFS_SKIP_SMUDGE=1 git clone` to fetch source only. Direct release downloads do not require Git or Git LFS.
